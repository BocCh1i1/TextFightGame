# TextFightGame 🎮

一个基于 Java 控制台的文字格斗游戏。玩家注册并登录后创建角色，分配属性点，与随机出现的敌人进行回合制战斗，在不断挑战中提升属性、冲击更高胜场。

纯 Java 标准库实现，无任何第三方依赖，适合作为 Java 入门练手项目或控制台游戏示例。

## ✨ 核心功能

### 1. 用户系统
- **注册**：用户名需 3~16 位、只能由字母数字组成（不能纯数字）、且唯一；密码需 3~8 位、由字母+数字组成、二次确认
- **登录**：需要用户名、密码和 5 位随机验证码（4 字母 + 1 数字，位置随机）
- **账号锁定**：密码连续输错 3 次，账号自动锁定，需联系"官方客服"

### 2. 角色创建
- 初始拥有 20 点属性，可自由分配到生命值、攻击力、防御力
- 每个属性点收益：HP +10、ATK +2、DEF +1

### 3. 回合制战斗
- 每场战斗随机遭遇一种敌人，共 4 种敌人各有专属技能
- 玩家拥有 3 个技能：普通攻击、强力一击、生命汲取
- 战斗胜利后恢复生命值，每 3 胜获得一次永久属性提升
- 敌人会随胜场数逐渐变强，挑战不断升级

## 🎯 敌人与技能一览

### 玩家技能

| 技能 | 消耗 | 效果 |
|------|------|------|
| 普通攻击 | 无 | 造成基础伤害 |
| 强力一击 | 10 HP | 造成 180% 攻击力伤害 |
| 生命汲取 | 10 HP | 恢复 10~30 点生命值 |

### 敌人类型

| 敌人 | 生命 | 攻击 | 防御 | 专属技能 |
|------|------|------|------|----------|
| 初级战士 | 80 | 15 | 10 | 猛击（130% 伤害） |
| 敏捷刺客 | 60 | 20 | 5 | 快速攻击（2 次 50% 伤害） |
| 重装坦克 | 100 | 10 | 15 | 防御姿态（下回合伤害减半） |
| 神秘法师 | 65 | 22 | 8 | 火球术（150% 伤害） |

## 🛠️ 技术栈与运行环境

- **语言**：Java（使用 Java 8+，推荐 JDK 8 及以上）
- **依赖**：无第三方依赖，仅使用 Java 标准库（`java.util.ArrayList`、`java.util.Random`、`java.util.Scanner`）
- **开发工具**：IntelliJ IDEA（也可用任意支持 Java 的 IDE 或命令行）

## 🚀 安装与启动

### 方式一：使用 IntelliJ IDEA（推荐）

1. 克隆仓库
   ```bash
   git clone https://github.com/你的用户名/TextFightGame.git
   ```
2. 打开 IntelliJ IDEA，选择 `File → Open`，打开项目目录
3. 等待项目加载完成
4. 右键 `src/APP.java`，选择 `Run 'APP.main()'`

### 方式二：使用命令行

```bash
# 进入项目目录
cd TextFightGame

# 编译（输出到 out 目录）
javac -encoding UTF-8 -d out src/APP.java src/UI/*.java src/domain/*.java

# 运行
java -cp out APP
```

> 注意：代码中包含中文和 emoji 输出，编译时务必指定 `-encoding UTF-8`。

## 📖 使用说明

1. **注册账号**：启动后选择 `2`，按提示输入用户名和密码
2. **登录游戏**：选择 `1`，输入用户名、密码，并正确输入验证码
3. **创建角色**：登录后分配 20 点属性点（输入 0~剩余点数的整数）
4. **开始战斗**：每回合从 3 个技能中选择一个（输入 1/2/3）
5. **继续挑战**：战斗胜利后选择是否继续（输入 `y` 继续，其他键退出）

## 🎮 游戏机制说明

- **伤害公式**：`伤害 = 攻击力 - 防御力`（最低 1 点）
- **敌人成长**：每场战斗胜利后，所有敌人 HP +8、ATK +2、DEF +1
- **玩家成长**：每 3 场胜利，玩家 maxHP +40、ATK +7、DEF +4
- **战后恢复**：胜利后恢复 30~60 点生命值
- **失败条件**：生命值归零即游戏结束
